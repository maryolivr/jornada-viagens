# ✈️ Jornada Viagens

O **Jornada Viagens** é um projeto de uma landing page moderna para uma agência de viagens, desenvolvido para praticar conceitos fundamentais de desenvolvimento web front-end, com foco total em design responsivo e semântica.


## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização moderna utilizando:
    - **Flexbox & CSS Grid**: Para layouts complexos e alinhamentos.
    - **Media Queries**: Para garantir que o site funcione em dispositivos móveis, tablets e desktops.
    - **Variáveis CSS**: Para facilitar a manutenção de cores e fontes.
- **Fontes Google**: Integração de tipografia externa para melhor design.

## 🛠️ Funcionalidades

- **Layout Responsivo**: O site se adapta automaticamente a diferentes tamanhos de tela (Mobile-first).
- **Menu de Navegação**: Links rápidos para as seções do site.
- **Seção de Destinos**: Exibição de cards com os principais pacotes de viagem.
- **Formulário de Contato/Newsletter**: Área para captura de leads ou dúvidas.
- **Banner Principal**: Chamada visual impactante (Hero section).
